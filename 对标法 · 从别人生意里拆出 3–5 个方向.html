对标法 · BENCHMARKING

从别人的生意里
拆出 3–5 个你能入手的方向

不靠灵感，靠拆解。先横向拆开多个对标对象，提取机会点，再组装成多个候选方向，最后用打分排序挑一个先验证。

1

圈定范围：在哪个“场”里找生意

先别急着找对标对象，先确定你要在哪个池塘里钓鱼。

🎯 怎么做

画三个圈，找交集，交集越小越好：① 我熟悉 / 有资源的　② 市场真有人掏钱的　③ 我愿意做 3 年以上的

❓ 问自己
  • 我过去的工作 / 生活里，哪些信息是我比别人更懂的？
  • 我身边的人最近半年为什么事付过钱？
  • 如果 3 年不赚钱，我还能坚持做这件事吗？
经验、人脉、工厂、渠道、身份
有人已经为此付过钱，不是“我觉得有需求”
不赚钱也愿意继续研究的领域
一句话，范围要小到能说清“不做哪些”
2

挑对标对象：3 类样本就够

不要只盯第一名，看第一名容易自卑，看不到机会。

🎯 怎么做

每类挑 1–2 个，总共 3–5 个：头部玩家看天花板，新锐黑马看当下打法，失败 / 退出者看坑在哪。

❓ 问自己
  • 他们卖什么给谁？大概多大体量？
  • 他们最近一年最大的变化是什么？
  • 那个退出的人，最后是被什么拖垮的？
看这个生意的终点
近 1–2 年跑出来的
看成本在哪爆掉
可写可不写，但写清楚能帮你后面判断
3

建对标维度：把生意拆成 6 个格子

用同一套模板拆所有人，这样才可比。每个格子写清“看什么指标”。

🎯 六个格子

客群 → 痛点 → 产品与定价 → 获客渠道 → 变现方式 → 成本结构。每个格子配 1–2 个能算的数。

❓ 问自己
  • 这些数字我能从哪拿到？（体验产品、翻评论区、看招聘信息、聊 3 个真实用户）
  • 哪个格子我完全填不出来？——那就是我的信息盲区
谁在买、什么身份、什么阶段
买之前他在纠结什么
卖什么、客单价多少、复购如何
用户从哪来、获客成本多少
一次卖货？订阅？服务费？
钱主要花在哪、毛利多少

每格只填“事实 + 数字”，不填感受。每行至少填一格即可。

🎯 三色标记

🟢 他们做得最好的 → 行业门槛；🟡 大家都差不多 → 行业规律；🔴 大家都缺的 → 你的机会

机会提取：至少拆出 3 个可乘之机

回到第 4 步的对标表，把“缝隙”一个个揪出来。这是产出多个方向的关键一步。

🎯 从哪找

🔴 大家都缺的——被将就的用户、被忽略的环节
🟡 大家都一样的——同质化最严重的地方，往往能用不同做法切入
🟢 你有而他们没有的——你的经验、关系、身份、地域、内容能力

方向组装：把机会点变成一个生意

上面每个机会点，自动展开成一张方向卡。给每个方向填一句话定位，并打三项分。

🎯 打分规则

可行性：我能不能做到（资源 / 能力）｜ 匹配度：跟我长期意愿契不契合｜ 需求热度：真的有人愿意掏钱吗
每项 1–5 分，三项相加满分 15。分数不是精确测量，只是帮你把模糊的直觉显性化。
